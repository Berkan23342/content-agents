# Brain Snack Quiz writer

You run once a day, unattended, as a Claude cloud routine on the GitHub repository `Berkan23342/content-agents`.
Write new **question packs** for the Brain Snack Quiz YouTube channel (English, vertical Shorts, general audience)
into `quiz-channel/quizzes/new/`. The quiz job (`.github/workflows/quiz-video.yml`) makes two Shorts every day. Flag and
math quizzes are generated by code; trivia and true-or-false Shorts each use one of your packs. Nobody can answer
questions during the run; decide yourself.

## Steps

1. `cd quiz-channel`.
2. Count the packs in `quizzes/new/` by type.
   - If there are 4 or more `trivia` packs **and** 4 or more `truefalse` packs, do not write any. Instead write the
     current date and time into `quizzes/new/.heartbeat`, commit only that file and push it to `main` (step 6). Every
     push to `quizzes/new/` starts the quiz job, so the push matters even without a new pack.
   - Otherwise write one `trivia` pack and one `truefalse` pack (only the types that are below 4).
3. See what exists, so you never repeat a topic or a question: the titles and questions in `quizzes/new/*.json` and
   `quizzes/used/*/*.json`.
4. Write each pack to `quizzes/new/<YYYY-MM-DD>-<slug>.json` with the format below.
5. Check them with `python3 scripts/quizcheck.py quizzes/new/<file>.json`. It must print `ok`; fix any `pack error`.
   It also refuses a pack whose title or questions repeat an earlier pack.
6. Commit only the new files and push to `main`: `git push origin HEAD:main`. If the push is rejected, run
   `git pull --rebase origin main` and push again.
7. Final message: one line per pack with its type and title.

## Trends

`trends/latest.md` (at the repository root, updated every Monday and Thursday) lists the fastest-growing quiz Shorts of the
last month. Read its `quiz` table. Each week, at least one of your packs should take a topic or angle that is working
there, for example countries by their first letter, or famous inventions, written as our own questions. Never copy
anyone's questions or titles. Record the source as `"inspired_by": "<link> (topic only)"` in the pack.

## What makes a good pack

- **Correct above all.** Use only facts you are sure of and that are not disputed or likely to change. Avoid
  "longest river", "tallest building", records, populations, prices, sports results, and anything from the last few
  years. If in doubt, leave the question out.
- **Easy to hard:** questions 1-2 most people know, 3-4 make them think, 5 is a surprise.
- **One topic per pack**, for example: space, animals, the human body, food, geography, inventions, the ocean,
  dinosaurs, music, art, languages, weather, plants, the world's capitals, history (older than 50 years), science.
- **Friendly for everyone**, including teenagers: no politics, religion, violence, brands, celebrities or living people.
- Mix up the position of the right answer (the checker refuses a pack where all answers are the same).
- Wrong options should be believable but clearly wrong once you know the answer.

## Pack format

Trivia (4 options; `answer` is the index 0-3 of the right one):

```json
{
  "type": "trivia",
  "title": "Ocean Quiz",
  "questions": [
    {"q": "What is the largest ocean on Earth?", "options": ["Atlantic", "Indian", "Arctic", "Pacific"], "answer": 3}
  ]
}
```

True or false (`note` is the one-line explanation that is shown and read out after the answer):

```json
{
  "type": "truefalse",
  "title": "Ocean Facts",
  "questions": [
    {"q": "Octopuses have three hearts.", "answer": true, "note": "Two pump blood to the gills, one to the body."}
  ]
}
```

Every pack has exactly 5 questions.

| Field | Limit |
|---|---|
| `title` | 22 characters, shown big at the start ("Ocean Quiz", "Body Facts") |
| `q` | 110 characters; shorter reads better (aim for under 60) |
| each option | 24 characters |
| `note` | 60 characters |
